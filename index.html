Linear and Log-Linear Trend Models: Calculating Predicted Values

Calculate and evaluate the predicted trend value for a time series, modeled as either a linear trend or a log-linear trend, given the estimated trend coefficients.

What is a time series — and what is a trend?

A time series is a set of observations of a variable over successive periods of time (for example, monthly stock market returns for the past 10 years, or a company's quarterly revenue). A series has a trend if a consistent pattern can be seen by plotting the data (i.e., the individual observations) on a graph. Because every observation is tied to a date, we can use the passage of time itself as the explanatory variable. For example, a seasonal trend in sales data is easily detected by plotting the data and noting a significant jump in sales during the same month(s) each year.

1. Linear trend model

A linear trend is a time-series pattern that can be graphed with a straight line. A downward-sloping line indicates a negative trend; an upward-sloping line indicates a positive trend. The dependent variable changes by a constant amount in each period. The independent variable is simply the time index t (1, 2, 3 … T).

Linear trend model
yt = b0 + b1(t) + εt
yt = value of the time series (the dependent variable) at time t
b0 = intercept at the vertical axis (y-axis)
b1 = slope coefficient (or trend coefficient) — the change in y per period
εt = error term (also called residual term or disturbance term)
t = time (the independent variable); t = 1, 2, 3 … T

The coefficients are estimated with ordinary least squares (OLS) regression. Don't let the model confuse you: it is very similar to the simple linear regression covered earlier; only here t takes on the value of the time period. The estimated (fitted) equation is used for prediction:

Prediction equation (estimated trend line)
ŷt = b̂0 + b̂1(t)
ŷt = predicted value of y (the dependent variable) at time t
b̂0 = estimated value of the intercept term
b̂1 = estimated value of the slope coefficient

To forecast, plug the time index into the equation: the prediction for period 2 is ŷ2 = b̂0 + b̂1(2), for period 3 it is ŷ3 = b̂0 + b̂1(3), and so on. Because every period adds b̂1, the forecast moves up (b̂1 > 0) or down (b̂1 < 0) by the same amount each period.

Worked example — using a linear trend model

Suppose a linear trend model has b̂0 = 1.70 and b̂1 = 3.0. Calculate ŷt for t = 1 and t = 2.

When t = 1: ŷ1 = 1.70 + 3.0(1) = 4.70
When t = 2: ŷ2 = 1.70 + 3.0(2) = 7.70

The two forecasts differ by exactly b̂1 = 3.0 — the signature of a linear trend.

2. Log-linear trend model

Time-series data — financial series in particular — often display exponential growth (growth with continuous compounding). The series grows (or decays) by a constant rate rather than a constant amount, so a straight line fits poorly: the plot is a curve. Following the curriculum wording: positive exponential growth (the variable increases) forms a convex curve, and negative exponential growth (the variable decreases at a constant rate of decay) forms a concave curve.

Log-linear (exponential) trend model
yt = eb0 + b1(t)
taking natural logs of both sides:
ln(yt) = ln(eb0 + b1(t)) ⇒ ln(yt) = b0 + b1(t)
yt = value of the dependent variable at time t
b0 = intercept term
b1 = constant rate of growth (continuously compounded)
e = base of the natural logarithm
t = time index = 1, 2, 3 … T

The key trick: after taking the natural log of the dependent variable, the model is linear in the coefficients, so ordinary regression of ln(yt) on t gives the estimates. The transformed data produce a linear trend line with a better fit and increase the predictive ability of the model. The slope b̂1 is the (continuously compounded) growth rate per period. Forecasting has two steps: (1) compute the forecast of ln(y), then (2) exponentiate it (y = eln y) to get back to the original units. Forgetting step 2 is the classic exam error.

Choosing a Trend Model and Its Limitations

Describe factors that determine whether a linear or a log-linear trend should be used with a particular time series and evaluate limitations of trend models.

Choosing between the two models

The first step is always to plot the data and look at its shape. A linear trend model may be appropriate if the data points appear to be equally distributed above and below the regression line.

Linear trend model

The data plot as a roughly straight line: the variable increases (or decreases) over time by a constant amount. Example: the inflation rate — a series that moves up and down around a steady, roughly constant path — suits a linear trend.

Log-linear trend model

The data plot as a non-linear (curved) line: the variable grows at a constant rate. Examples: stock prices, a company's sales, financial series that compound. Plotting ln(y) against time should give a straight line.

Figure (redrawn): the same exponentially growing data. A straight line mis-fits (residuals come in long runs of + or −); the log-linear model fits the transformed data evenly.
Quick decision rule
constant amount of change → linear trend model
constant rate of change (curved plot) → log-linear trend model

Another way to compare: look at the residuals

A good fit shows residuals scattered randomly and evenly above and below zero. If a linear model is fitted to data that grow at a constant rate, the residuals will be persistently positive or persistently negative for stretches of time (predictable clusters). In other words, when the residuals from a linear trend model are serially correlated, a log-linear trend model may be more appropriate: by taking the log of the y variable, a regression line can better fit the data (and yields more accurate forecasts). Financial data (e.g., stock indices and stock prices) and company sales data are often best modeled with log-linear models. In that case a log-linear model is usually the better choice. A trend model whose residuals are still predictable has not captured the pattern in the data.

Limitations of trend models

Recall that one of the assumptions underlying linear regression is that the residuals are uncorrelated with each other; a violation of this assumption is called serial correlation or autocorrelation. The main limitation: trend models easily have serial correlation — the error in one period is correlated with the error in the next. Serial correlation violates the regression assumption that errors are independent, so the standard errors, t-statistics and conclusions from the regression cannot be trusted, and the forecasts are less reliable.

The standard test is the Durbin-Watson (DW) test (covered in Reading 1 for multiple regression):

DW statisticInterpretation
DW ≈ 2No serial correlation in the residuals
DW significantly ≠ 2 (below 2)Positive serial correlation in the residuals
DW significantly ≠ 2 (above 2)Negative serial correlation in the residuals

For a trend model, if the DW test shows the residuals are serially correlated, a trend model — even a log-linear one — is not appropriate. Time series are usually better modeled with an autoregressive (AR) model, in which the lagged dependent variable is used as an independent variable (LOS 2.c–2.f).

Applying it — the real-estate-loan regression (Module Quiz 2.1)

A linear trend regression of 45 quarters of data in the Module Quiz reports Durbin-Watson = 0.601. That is far below 2, so the residuals show strong positive serial correlation — the trend model is inadequate even though R² is a high 0.968. A high R² does not rescue a model with serially correlated errors.

Professor's Note

Remember this chain of logic because it drives the whole reading: trend model → check DW → serial correlation found → switch to an AR model. Also remember the contrast to come in LOS 2.e: for AR models, the DW test is not used — you test autocorrelations of residuals with a t-test.

Key Concepts
  • Linear trend: constant amount of change, data plot as a straight line. Log-linear: constant rate of change, data plot as a curve.
  • Persistent runs of positive or negative residuals in a linear trend model suggest a log-linear model (or a different model) is needed.
  • Trend models are prone to serial correlation; test with Durbin-Watson (DW ≈ 2 → no serial correlation).
  • If serial correlation is present, a trend model is inappropriate → use an autoregressive (AR) model.

Covariance Stationarity

Explain the requirement for a time series to be covariance stationary and describe the significance of a series that is not stationary.

What is an autoregressive (AR) model?

An autoregressive (AR) model is a regression in which the dependent variable is regressed against one or more lagged values of itself. The simplest version uses just the previous period's value:

First-order autoregressive model — AR(1)
xt = b0 + b1xt−1 + εt
xt = value of the time series at time t
b0 = intercept at the vertical axis (y-axis)
b1 = slope coefficient
xt−1 = value of the time series at time t − 1
εt = error term (residual or disturbance term)
t = time; t = 1, 2, 3 … T

The coefficients are estimated by OLS, and statistical inferences (t-tests, confidence intervals) are based on those OLS estimates. These inferences are only valid if the time series is covariance stationary — that is the crux of this LOS.

Covariance stationarity: three requirements

A time series is covariance stationary if it satisfies all three conditions:

1
Constant and finite expected value. The expected value of the time series is constant over time (this constant, finite value is the series' mean-reverting level, LOS 2.f).
▼
2
Constant and finite variance. The time series' volatility around its mean does not change over time.
▼
3
Constant and finite covariance between values at any given lag. The covariance of the time series with leading or lagged values of itself is constant.
Illustration: only the left series has a stable mean, stable variance and stable covariance structure. A trending mean or changing volatility breaks covariance stationarity.

The significance of a series that is not covariance stationary

If a time series is not covariance stationary, the regression's OLS estimates and the test statistics based on them are unreliable (statistical inferences are invalid). The estimated coefficients no longer tell you about a stable relationship, so the model cannot be used to forecast with confidence. Before running an AR model you must therefore check stationarity and, if it fails, transform the data (for example by first-differencing — LOS 2.j and 2.k).

Applying it — Module Quiz 2.2, Q1

A plot of annual data for time series X rises smoothly, and faster and faster, over the years. Its mean is clearly not constant (it keeps drifting up), so the series is not covariance stationary — it fails the "constant and finite expected value" condition.

Professor's Note

Learn the three conditions by their keywords: expected value, variance, covariance — each constant and finite. Exam questions typically show a plot (trend, changing spread) or describe a series and ask which condition is violated, or ask what the implication is (invalid inference).

Key Concepts
  • An AR model regresses a variable on its own lagged values; OLS inference is valid only if the series is covariance stationary.
  • Covariance stationary = constant and finite (1) expected value, (2) variance, (3) covariance with its own leading/lagged values.
  • If the series is not covariance stationary, regression estimates and inferences are unreliable; the data must be transformed first.

AR Models of Order p and Forecasting

Describe the structure of an autoregressive (AR) model of order p and calculate one- and two-period-ahead forecasts given the estimated coefficients.

AR models of order p

An AR model of order p uses p lagged values of the time series as independent variables. The AR(1) model uses one lag, the AR(2) model uses two lags:

Second-order autoregressive model — AR(2)
xt = b0 + b1xt−1 + b2xt−2 + εt
General form — AR(p)
xt = b0 + b1xt−1 + b2xt−2 + … + bpxt−p + εt
p = the number of lagged values that the AR model includes as independent variables

Forecasting with an AR model — the chain rule of forecasting

Forecasts are made one period at a time. The one-step-ahead forecast uses the latest actual value; the two-step-ahead forecast then uses the one-step-ahead forecast in place of the (not yet observed) actual value. This is why you must calculate the one-step-ahead forecast before you can compute the two-step-ahead forecast.

Chain rule for an AR(1) model
x̂t+1 = b̂0 + b̂1xt
x̂t+2 = b̂0 + b̂1x̂t+1
xt = actual (current) value; x̂ = forecast value
Worked example — forecasting

An AR(1) model has the prediction equation xt = 1.2 + 0.45xt−1. Calculate a two-step-ahead forecast if the current value of x is 5.0.

One-step-ahead: if xt = 5, then x̂t+1 = 1.2 + 0.45(5) = 3.45.
Two-step-ahead: if x̂t+1 = 3.45, then x̂t+2 = 1.2 + 0.45(3.45) = 2.75.

Extension: keep chaining the forecasts and they converge to 1.2 / (1 − 0.45) = 2.18 — the mean-reverting level (LOS 2.f). The farther ahead you forecast, the less the current value matters.
Same idea for an AR(2) model (applying the chain rule)

x̂t+1 = b̂0 + b̂1xt + b̂2xt−1 (two actual values).
x̂t+2 = b̂0 + b̂1x̂t+1 + b̂2xt (one forecast, one actual).

Professor's Note

The most common mistake: in the two-step forecast, plugging the actual current value again instead of the one-step forecast. Always substitute the forecast x̂t+1. Multi-period forecasts are also less certain than one-period forecasts because each step builds on an estimate rather than an observed value.

Key Concepts
  • An AR(p) model has p lagged values of the dependent variable as regressors.
  • Forecasts are chained: compute x̂t+1 from the actual xt, then x̂t+2 from x̂t+1.
  • Example: xt = 1.2 + 0.45xt−1 with xt = 5 → 3.45 → 2.75.

Testing AR Model Fit with Residual Autocorrelations

Explain how autocorrelations of the residuals can be used to test whether the autoregressive model fits the time series.

Why test the residuals?

If an AR model is correctly specified, its residuals should look like random noise: no residual should be predictable from earlier residuals. Serial correlation (autocorrelation) of the residuals means the forecast error in one period is related to the error in other periods. When it is present, the model has not captured all the dynamics in the data and the coefficient standard errors — hence the t-tests — are unreliable. So we test whether the residual autocorrelations are significantly different from zero.

The three-step test

1
Estimate the AR model being evaluated using linear regression. Start with a first-order AR model [i.e., AR(1)]: xt = b0 + b1xt−1 + εt.
▼
2
Calculate the autocorrelations of the model's residuals (the level of correlation between the forecast errors from one period to the next).
▼
3
Test whether the autocorrelations are significantly different from zero. If the model is correctly specified, none of the autocorrelations will be statistically significant. Use a t-test (not DW), two-tailed.
Test statistic for each residual autocorrelation
t = ρεt, εt−k / (1/√T)
ρεt, εt−k = estimated correlation of error term t with the k-th lagged error term
Standard error = 1/√T, where T = number of observations
Degrees of freedom = T − 2
H0: the residual autocorrelation = 0 | Ha: the residual autocorrelation ≠ 0 (two-tailed)
Decision: reject H0 if |t| > critical t-value (tc) with T − 2 degrees of freedom

Mean Reversion and the Mean-Reverting Level

Explain mean reversion and calculate a mean-reverting level.

Mean reversion

A time series exhibits mean reversion if it has a tendency to move toward its mean. In other words, the series tends to decline when the current value is above the mean and rise when the current value is below the mean.

If the series is at its mean-reverting level, the model predicts that the next value will be the same as the current value: x̂t = xt−1. That single idea gives us a formula for the mean-reverting level of an AR(1) model:

1
Start from the AR(1) model: xt = b0 + b1xt−1.
▼
2
At the mean-reverting level, xt = xt−1, so xt = b0 + b1xt.
▼
3
Solve for xt: xt(1 − b1) = b0.

In-sample forecasts

Forecasts within the range of data (the time period) used to estimate the model — the sample or test period. Instability of Coefficients

Explain the instability of coefficients of time-series models.

Why coefficients are unstable

Financial and economic time series inherently exhibit some form of instability or nonstationarity. Financial and economic conditions are dynamic, so the regression coefficients estimated in one period may be quite different from those estimated during another period.

The sample-period tradeoff

Longer sample periodShorter sample period
Statistical reliability✔ Greater (more observations)✘ Lower (fewer observations)
Stability of coefficients✘ Lower — more chance the underlying economic process changed✔ Models estimated with shorter time series are usually more stable

There is therefore a tradeoff between the increased statistical reliability of longer time periods and the increased stability of the estimates from shorter periods.

What matters most when choosing the sample period

The primary concern is the underlying economic processes. Ask:

Have there been regulatory changes?

A change in rules can alter how the variable behaves, so older data may describe a different process.

Has there been a dramatic change in the economic environment?

If the environment changed substantially, the relationship estimated before the change may not hold afterward.

Conclusion

If the answer to either question is yes, the historical data may not provide a reliable model. Merely examining the significance of the residual autocorrelations will not tell you whether the model is valid — you must also examine whether the data are covariance stationary.

Professor's Note

Link to LOS 2.o: a structural change (a permanent shift in the data at some date) is the extreme case of instability, and the remedy there is to estimate two separate models, one for each distinct period (Module Quiz 2.5, Q1 — answer C). The same answer key adds that there is no accepted formula for the optimal sample period (graphical inspection of the data may help), and that you may strategically choose a longer or shorter sample, or a first- or second-order AR model.

Key Concepts
  • Financial and economic series are dynamic, so coefficients can differ across sample periods (instability / nonstationarity).
  • Shorter samples → more stable estimates; longer samples → more statistical reliability. There is a trade-off.
  • Primary concern: has the underlying economic process changed (regulation, economic environment)? If yes, historical data may not give a reliable model.
  • Residual-autocorrelation tests alone cannot prove a model is valid — also check covariance stationarity.

Random Walks vs Covariance-Stationary Processes

Describe characteristics of random walk processes and contrast them to covariance stationary processes.

The simple random walk

If a time series follows a random walk, the predicted value in one period equals the value in the previous period plus a random error term. The best forecast of xt is simply xt−1.

Simple random walk
xt = xt−1 + εt
Best forecast of xt is xt−1
1. E(εt) = 0 — the expected value of each error term is zero
2. E(εt²) = σ² — the variance of the error terms is constant
3. E(εiεj) = 0 for i ≠ j — there is no serial correlation in the error terms

Random walk with a drift

If the series follows a random walk with a drift, the intercept is not zero: in addition to the random error, the series is expected to increase or decrease by a constant amount each period.

Random walk with a drift
xt = b0 + b1xt−1 + εt
b0 = the constant drift (≠ 0)
b1 = 1
Illustration: random walks wander with no tendency to return to a mean; the covariance-stationary AR(1) keeps returning to its mean-reverting level.

Random walks are NOT covariance stationary

Write both cases in the general AR(1) form:

Random walk, general form
xt = b0 + b1xt−1 + εt
b0 = 0 (random walk without a drift)
b0 ≠ 0 (random walk with a drift)
b1 = 1 (random walk with or without a drift)
Mean-reverting level of a random walk
b0 / (1 − b1) = b0 / (1 − 1) = b0 / 0 → undefined (infinite)

Implications of Unit Roots and First Differencing

Describe implications of unit roots for time-series analysis, explain when unit roots are likely to occur and how to test for them, and demonstrate how a time series with a unit root can be transformed so it can be analyzed with an AR model.

Implications of a unit root

If the coefficient on the lag variable is 1, the series is not covariance stationary. When the lag coefficient equals one, the series is said to have a unit root and follows a random walk. Since a random walk is not covariance stationary, modeling such a series in an AR model on its levels can lead to incorrect inferences: the OLS estimates and t-tests are unreliable.

When do unit roots occur?

Whenever the series behaves as a random walk (with or without drift) — i.e., the best predictor of next period's value is this period's value plus noise. Many financial and economic series behave like this (in the notes' example, the capacity-utilization series "probably contains a unit root"). That is why you must test for a unit root before using an AR model on a level series.

How do we test for them?

Two ways (details in LOS 2.k): (1) estimate an AR model and examine the significance/decay of residual autocorrelations, or (2) perform the Dickey-Fuller test.

The fix: first differencing

If we believe a series is a random walk (has a unit root), we can transform the data into a covariance-stationary series with first differencing: subtract the value of the series in the immediately preceding period from the current value to define a new dependent variable, y. By taking first differences you model the change in the value of the series.

The Dickey-Fuller Unit Root Test

Describe the steps of the unit root test for nonstationarity and explain the relation of the test to autoregressive time-series models.

Two ways to test for non-stationarity

Method 1 — AR model + autocorrelations

Estimate an AR model and examine the statistical significance of the autocorrelations at various lags (LOS 2.e approach). A stationary process will usually have residual autocorrelations that are insignificantly different from zero at all lags, or that decay to zero as the number of lags increases.

Method 2 — Dickey-Fuller (DF) test

A more definitive test for a unit root. Because of statistical reasons you cannot directly test whether the AR coefficient b1 equals 1, so Dickey and Fuller devised an indirect test.

The Dickey-Fuller transformation

If an AR(1) model has b1 = 1 it has a unit root and no finite mean-reverting level (it is not covariance stationary). Dickey and Fuller (1) start with the basic AR(1) form and (2) subtract xt−1 from both sides:

Dickey-Fuller transformation
(1) xt = b0 + b1xt−1 + ε
(2) xt − xt−1 = b0 + b1xt−1 − xt−1 + ε ⇒ xt − xt−1 = b0 + (b1 − 1)xt−1 + ε
Let g = (b1 − 1). Then b1 = 1 ⇔ g = 0

Rather than testing directly whether the original coefficient differs from 1, they test whether the transformed coefficient (b1 − 1) differs from zero, using a modified t-test. If (b1 − 1) is not significantly different from zero, then b1 must equal 1 and the series has a unit root.

Dickey-Fuller hypotheses
H0: g = 0 (b1 = 1; the time series has a unit root)
Ha: g < 0 (no unit root; covariance stationary — the standard one-sided alternative; the notes state only the null)
Test statistic: a t-type statistic on g — but compared with Dickey-Fuller critical values, not conventional t-table values

Seasonality: Testing, Correcting and Forecasting

Explain how to test and correct for seasonality in a time-series model and calculate and interpret a forecasted value using an AR model with a seasonal lag.

What is seasonality?

Seasonality in a time series is a pattern that tends to repeat from year to year. One example is monthly sales data for a retailer: because sales vary with the time of year, this month's sales (xt) are likely related to sales for the same month last year (xt−12). When seasonality is present, the model is misspecified (and unreliable for forecasting) unless the AR model incorporates the effects of the seasonality.

Illustration: a quarterly series with a repeating yearly pattern. Each Q1 is related to the previous year's Q1 — four periods earlier.

Step 1 — Detect seasonality

Seasonality is tested by calculating the autocorrelations of the error terms (residuals) of the AR model and applying the t-test from LOS 2.e. A statistically significant autocorrelation at the lag that matches the periodicity of the data indicates seasonality: lag 4 for quarterly data, lag 12 for monthly data.

  • Forecast with the chain rule, using logs if the model is in logs, then exponentiate (e.g., 603,378.52).

ARCH: Autoregressive Conditional Heteroskedasticity

Explain autoregressive conditional heteroskedasticity (ARCH) and describe how ARCH models can be applied to predict the variance of a time series.

What is ARCH?

In an AR model, autoregressive conditional heteroskedasticity (ARCH) exists if the variance of the residuals in one period is dependent on the variance of the residuals in a previous period. When this condition exists, the standard errors of the regression coefficients in AR models and the hypothesis tests of these coefficients are invalid.

Illustration: with ARCH, volatility clusters — big shocks follow big shocks and quiet periods follow quiet periods.

Testing for ARCH with an ARCH model

An ARCH model is used to test for autoregressive conditional heteroskedasticity. An ARCH(1) time series is one for which the variance of the residuals in one period is dependent on (a function of) the variance of the residuals in the preceding period. To test whether a series is ARCH(1), regress the squared residuals from an estimated time-series model on the first lag of the squared residuals:

ARCH(1) regression
ε̂t² = a0 + a1ε̂t−1² + μt
ε̂t² = squared residuals from the estimated time-series model
ε̂t−1² = the first lag of the squared residuals
a0 = the constant; μt = an error term
Test: if a1 is statistically different from zero, the time series is ARCH(1)
Value of a1Meaning
a1 = 0Variance is constant from period to period (no ARCH)
a1 > 0 (statistically significant)Variance increases over time — the error terms exhibit heteroskedasticity (ARCH present)
a1 < 0Variance decreases over time (per the Professor's Note / slides)

Correcting for ARCH

If a time-series model contains ARCH errors, regression procedures that correct for heteroskedasticity, such as generalized least squares (GLS), must be used to develop a predictive model. Otherwise the standard errors of the model's coefficients will be incorrect, leading to invalid conclusions.

Predicting the variance of a time series

If a series has ARCH errors, an ARCH model can also be used to predict the variance of the residuals in future periods. For an ARCH(1) pattern, use the model in period t to predict the variance in period t + 1:

Predicted variance (ARCH(1))
σ̂t+1² = â0 + â1ε̂t²

Nonstationarity and Cointegration in Two-Series Regressions

Explain how time-series variables should be analyzed for nonstationarity and/or cointegration before use in a linear regression.

Regressing one time series on another

Occasionally an analyst regresses one time series on another time series. Example: using the market model to estimate a stock's equity beta, the analyst regresses a time series of the stock's returns (yt) on a time series of market returns (xt):

Regression of two time series
yt = b0 + b1xt + ε
yt = value of time series y at time t
xt = value of time series x at time t

Now there are two time series, and either or both could be non-stationary. The analyst first runs separate Dickey-Fuller tests on each series for unit roots. There are five possible outcomes:

#Result of the separate DF testsCan linear regression be used?
1Both time series are covariance stationaryYes — coefficients should be statistically reliable
2Only the dependent variable series is covariance stationaryNo — not reliable
3Only the independent variable series is covariance stationaryNo — not reliable
4Neither series is covariance stationary and the two are not cointegratedNo — not reliable
5Neither series is covariance stationary and the two are cointegratedYes — reliable

Cointegration

Cointegration means two time series are economically linked (related to the same macro variables) or follow the same trend, and that relationship is not expected to change. If two series are cointegrated, the error term from regressing one on the other is covariance stationary and the t-tests are reliable. Therefore Scenario 5 produces reliable regression estimates, whereas Scenario 4 does not.

Illustration: both pairs are non-stationary, but only the cointegrated pair keeps a stable gap (a stationary error term).

Testing for cointegration — the DF-EG test

1
Run the regression of one series on the other: yt = b0 + b1xt + ε.
▼
2
Test the residuals for a unit root using the Dickey-Fuller test with critical t-values calculated by Engle and Granger (the DF-EG test). H0: the residuals have a unit root (series not cointegrated).
▼
3
Reject H0 → the error terms are covariance stationary → the two series are cointegrated → the regression can be used to model their relationship.
Fail to reject → not cointegrated → the regression is not reliable.

Professor's Note

For the exam, remember that the Dickey-Fuller test does not use the standard critical t-values used to test individual regression coefficients, and the DF-EG test adjusts them further to test for cointegration. You do not have to know the critical values — just remember that, as with the regular DF test, if the null is rejected, the series (of error terms) is covariance stationary and the two time series are cointegrated. (Slide wording: H0 = the error has a unit root; Ha = no unit root, i.e., the two series are cointegrated.)

Applying it — Module Quiz 2.5, Q3

Linear regression is least appropriate when one of the series has a unit root and the other does not (B). It is fine if neither series has a unit root (A), or if both have a unit root and are cointegrated (C).

Key Concepts
  • Two-series regression: (1) neither has a unit root → regression usable; (2) only one has a unit root → invalid; (3) both have unit roots and are cointegrated → usable; (4) both have unit roots but are not cointegrated → invalid.
  • Cointegration = the series are economically linked / share a trend and the relationship will not change; the regression error term is covariance stationary.
  • Test: DF test on the regression residuals with Engle-Granger critical values (DF-EG). Reject the null → cointegrated.

Choosing an Appropriate Time-Series Model

Determine an appropriate time-series model to analyze a given investment problem and justify that choice.

An eight-step guide to choosing a time-series model

To determine which model best suits your needs, follow these guidelines (they tie together everything in this reading):

1
Determine your goal. Are you modeling the relationship of a variable to other variables (e.g., cointegrated time series, cross-sectional multiple regression)? Or modeling a variable over time (e.g., a trend model)?
▼
2
Plot the variable over time (for a single-variable time-series analysis) and look for signs of non-stationarity: non-constant variance (heteroskedasticity), non-constant mean, seasonality, or structural change.
▼
3
If there is no seasonality or structural shift, use a trend model. Data on a straight line with an upward/downward slope → linear trend model. Data in a curve → log-linear trend model.
▼
4
Run the trend analysis, compute the residuals and test for serial correlation with the Durbin-Watson test. No serial correlation → you can use the model. Serial correlation → use another model (e.g., AR).
▼
5
If the data has serial correlation, re-examine the data for stationarity before running an AR model. If not stationary, treat the data: linear trend → first-difference the data; exponential trend → first-difference the natural log; structural shift → run two separate models; seasonal component → incorporate the seasonality in the AR model.
▼
6
After first-differencing, if the series is covariance stationary, run an AR(1) model and test for serial correlation and seasonality. No remaining serial correlation → you can use the model. Otherwise add lagged values (including a seasonal lag, e.g., the 12th lag for monthly data) until the serial correlation is modeled away.
▼
7
Test for ARCH. Regress the squared residuals on squares of lagged residuals and test whether the coefficient is significantly different from zero. Not significant → you can use the model. Significant → ARCH is present; correct using generalized least squares.
▼
8
If you have two statistically reliable models and want to know which forecasts better, calculate their out-of-sample RMSE (the lower, the better).

Structural change

A structural change is indicated by a significant shift in the plotted data at a point in time that seems to divide the data into two or more distinct patterns. In Figure 2.3 the series shifts at point a. In this situation you have to run two different models — one using the data before and one using the data after that date — and test whether the series has actually shifted. If it has shifted significantly, a single model spanning the entire period (both patterns) will likely produce unreliable results.
